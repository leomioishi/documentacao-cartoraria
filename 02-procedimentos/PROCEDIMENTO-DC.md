# PROCEDIMENTO DC

## Objetivo
Detectar, criar, completar, reparar e sincronizar a estrutura registral de uma Jornada.

## Ordem obrigatória
1. Detectar.
2. Preservar.
3. Completar o que falta.
4. Registrar.
5. Sincronizar.
6. Verificar.
7. Declarar DC-OK somente se local e Cloud estiverem íntegros e alinhados.

## Classificação
- INEXISTENTE
- PARCIAL
- DC-PC
- DC-CD
- DESSINCRONIZADO
- DC-OK

## Proibição
Nunca declarar DC-OK sem verificar:
- Git local;
- remote origin;
- repositório remoto;
- branch;
- working tree;
- sincronização push/pull.
